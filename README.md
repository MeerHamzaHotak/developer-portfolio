# Personal Portfolio Website

## Overview

This is a modern, responsive personal portfolio website built using HTML, CSS, and JavaScript.  
It is designed to professionally showcase my skills, projects, and technical experience in a clean and structured way.

The layout is fully responsive and optimized for all screen sizes, including desktop, tablet, and mobile devices.

---

## Features

- Fully responsive design (mobile, tablet, desktop)
- Clean and modern UI/UX design
- Dedicated sections for About, Skills, Projects, and Contact
- Project showcase with structured presentation
- Smooth navigation and user-friendly layout
- Optimized for performance and readability

---

## Technologies Used

- HTML5 – Structure and content
- CSS3 – Styling and responsive design
- JavaScript (Vanilla) – Interactivity and dynamic behavior
